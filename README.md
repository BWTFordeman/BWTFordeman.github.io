# Little escapes

Three browser games, made for a little escape.

[Visit the game hub](https://bwtfordeman.github.io/)

- **Sideways drift club:** a solo keyboard drifting prototype with four seasonal circuits, free driving, 90-second runs, local records, six paint colors, and original synthesized sound.
- **Hollowlight:** a cozy autumn village with eight activities.
- **Afterdark:** lantern-lit zombie survival in the old borough.

Sideways controls: WASD or arrows to drive, Space for the handbrake, R to recover, C to change camera, and Esc to pause. Desktop WebGL is required.

This repository contains the compiled web release. Development sources are maintained separately. The concept illustrations are visual-development studies, not gameplay screenshots.
